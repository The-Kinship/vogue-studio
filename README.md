# Rafter Cat's Vogue Studio

Simple click-and-drag posing for FFXIV GPose (Dalamud plugin), working together with Brio.
Big circles on your character's joints: click a body part, drag it where you want. No gizmos.
Brio holds the pose and still handles hands, feet and fine detail.

`/vogue` opens it.

Install link (Dalamud > Settings > Experimental > Custom Plugin Repositories):
`https://raw.githubusercontent.com/The-Kinship/vogue-studio/main/repo.json`
